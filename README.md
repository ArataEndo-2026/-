# 個人情報取扱主任者　一問一答（ローカル版）

VS Code のローカル環境だけで動く、虫食い＋○×の一問一答アプリです。
サーバー不要・ネット接続不要・外部ライブラリなしです。

## ファイル構成

```
個人情報取扱主任者/
├── index.html    画面の骨組みとスタイル（CSS）
├── app.js        表示・採点・保存のロジック
├── questions.js  問題データ（ここだけ編集すれば問題を増やせます）
└── README.md     このファイル
```

問題を増やすだけなら `questions.js` だけを触れば十分です。
`index.html` は `questions.js` → `app.js` の順に読み込みます（この順番を入れ替えると動きません）。

## 起動方法

どちらでもOKです。

1. **そのまま開く**：`index.html` を右クリック →「ブラウザで開く」（またはダブルクリック）
2. **Live Server 拡張**：VS Code の拡張機能「Live Server」を入れて、`index.html` を右クリック →
   `Open with Live Server`（保存すると自動で再読み込みされるので、問題を編集しながら確認するときに便利）

途中経過の保存はブラウザの localStorage を使うため、ファイルを直接開く方法（`file://`）だと
ブラウザの設定によって保存が効かない場合があります。保存が効かなくてもアプリ自体は普通に動きます。
確実に保存させたいときは Live Server で開いてください。

## 機能

- **虫食い問題**：条文の空欄に入力 →「答え合わせ」で正誤＋正解＋解説を表示
- **同じ記号＝同じ答え**：`(1)` が複数ある問題は、1か所入力すると同じ番号の空欄に自動で反映されます
- **○×問題**：○か×を押すと即判定。**正解でも解説が必ず表示されます**
- 1問ずつ表示（前へ／次へ）、出題範囲の絞り込み（虫食いのみ・○×のみ・カテゴリ別）
- 順番シャッフル、空欄の幅を字数に合わせる／一律にする切り替え（切り替えても入力中の場所から動きません）
- 上部のバーは**解答が済んだ割合**（問題を移動しただけでは進みません）。スコアは `解答 3 / 44　正解 2` の形で出ます
- 最後に正解数を表示し、**間違えた問題だけ復習**できます
  - 正答率の分母は**出題数**です。飛ばした問題があるときは「解答したなかでは○%」も併記します
- **やり直し**：答え合わせのあとに出る「この問題をやり直す」で、その問題だけ解答を消してもう一度解けます
- **誤操作の防止**：空欄が全部未入力のまま答え合わせを押しても、不正解にはならず警告だけ出ます
- **復習リスト（間違えた問題の記録）**：詳しくは後述。出題範囲で「復習リスト」を選ぶと、間違えた問題だけを解けます
- **項目ごとの誤答率**：解いている画面の右上に「この項目 誤答 2 / 5（40%）」、結果画面には全項目の一覧が出ます
- **途中経過の自動保存**：解答・現在の問題・設定はブラウザに保存され、閉じても次に開いたところから再開できます
  （`questions.js` の問題を追加・削除すると保存内容は破棄され、最初から始まります）
- **うっかりリセットの防止**：解答済みがある状態で出題範囲・シャッフルを変更したり「最初から」を押すと確認が出ます。
  キャンセルすると設定も解答もそのまま残ります
- **ダークモード**：OS／ブラウザの設定に追従して配色が切り替わります
- キーボード操作：
  - `Enter`＝答え合わせ／次へ
  - `←` `→`＝問題の移動。**空欄に入力中は `Ctrl`（または `Alt`）＋ `←` `→`**（矢印だけだとカーソル移動になります）
  - ○×問題では `o` / `x`（または `1` / `2`）で即回答

## 復習リストと項目ごとの成績

間違えた問題は自動で**復習リスト**に入ります。データベースは使わず、ブラウザの localStorage
（キー `kojin-quiz.stats.v1`）に問題ごとの「解答回数・誤答回数・連続正解数」を持つだけです。

### リストに入る／外れる条件

| | 条件 |
|---|---|
| 入る | 1回でも間違えた時点で入る（外したあとでも、また間違えれば戻ります） |
| 自動で外れる | **3回連続で正解**したとき |
| 自動で外れない | **通算5回以上間違えた問題**。「外す」ボタンを押すまで残ります |

連続正解のカウントは、途中で1回でも間違えると 0 に戻ります。
答え合わせのあとに「連続正解 2 / 3（あと1回で外れます）」と出るので、残り回数はその場で分かります。

### 使い方

- **復習リストだけ解く**：出題範囲のプルダウンで「復習リスト（間違えた問題）（○問）」を選ぶ
  （結果画面の「復習リストを解く」ボタンからも切り替えられます）
- **手動で外す**：結果画面の復習リスト一覧にある各問題の「外す」ボタン
  （5回以上間違えた問題はここからしか外せません）
- **記録を消す**：ヘッダーの「記録をリセット」。復習リストと項目ごとの成績が全部消えます（確認が出ます）

### 数え方の細かい話

- 成績に数えるのは **1周につき1問1回だけ**です。答えを見たあとに「この問題をやり直す」で正解しても、
  連続正解には数えません（見てから正解した分で卒業してしまわないようにするためです）
- 「最初から」や出題範囲の変更では**記録は消えません**。消えるのは途中経過だけです
- `questions.js` から問題を削除すると、その問題の記録も読み込み時に捨てられます

## 採点のゆるさ

入力は次のように正規化してから比較します。厳しすぎて困ることは少ないはずです。

- 全角／半角の違いを無視（`３年` = `3年`）
- 空白（半角・全角）を無視
- 句読点・かっこ（`、。・「」（）`）を無視

それでも表記ゆれで×になる場合は、`questions.js` の答えを配列にすると別表記も正解になります。

```js
answers: { 1: ['3年ごと見直し', '三年ごと見直し'] }
```

## 問題の追加方法

`questions.js` の配列に追記するだけです。

書き間違いは**起動時に自動チェック**され、見つかると画面上部に赤いバナーで一覧が出ます
（ブラウザのコンソールにも同じ内容が出ます）。チェックしている内容は次のとおりです。

- `[[1]]` を `[1]` と書いてしまい、空欄が 0 個になっている（放置すると自動的に「正解」になってしまうため）
- 本文の `[[2]]` に対応する `answers` がない／`answers` にあるのに本文に空欄がない
- `id` の重複、`answer` が `'○'` `'×'` 以外、`type` が `fill` `ox` 以外
- `id` `type` `title` `text` の欠落

### 虫食い問題

```js
{
  id: 'f99',                       // 他とかぶらない任意のID
  cat: '安全管理措置等',            // 出題範囲のプルダウンに出る分類
  type: 'fill',
  title: '問題のタイトル',
  text: `個人情報取扱事業者は、その取り扱う個人データの[[1]]のために必要かつ適切な措置を講じなければならない。[[1]]は重要である。`,
  answers: { 1: '安全管理' },      // [[1]] の答え。同じ番号は同じ答え
  note: 'ここに解説（省略可・null でもOK）。**ここは太字**になります'
}
```

- 解説（`note`）は `**〜**` で囲んだ部分だけ**太字**になります。改行は `\n` で入れられます。
  それ以外の HTML タグは書いてもそのまま文字として表示されます（安全のため意図的にそうしています）。

- `[[1]]` `[[2]]` … が空欄になります。**番号は文章の登場順**に振ってください。
- 同じ語が何度も出てくる場合は、同じ番号を使い回します。

### ○×問題

```js
{
  id: 'o99',
  cat: '○×（問10）',                // 既存の○×問題はこの分類に入っています
  type: 'ox',
  title: '問10 H',
  text: `ここに問題文。`,
  answer: '×',                     // '○' または '×'
  note: '正解でも表示される解説。'
}
```
